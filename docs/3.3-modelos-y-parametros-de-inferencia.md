## 3.3 · Modelos y parámetros de inferencia

| Tarea | Modelo (Bedrock) | Parámetros | Por qué |
|---|---|---|---|
| Generar imagen | `stability.stable-image-core-v1:1` (Stability AI, región `us-west-2`) | `prompt` (+ sufijo de estilo), `negative_prompt` opcional, `seed` opcional, `output_format=png` | El prompt describe la imagen; la semilla permite reproducir exactamente un resultado que gustó al equipo. Este modelo (sucesor de Stable Diffusion XL en Bedrock) no expone `cfg_scale` ni `steps` — solo estos cuatro campos. |
| Corregir texto | `us.anthropic.claude-sonnet-4-5-20250929-v1:0` (Claude Sonnet 4.5, vía *inference profile*) | `temperature=0.2`, `max_tokens=1200` | Se busca precisión gramatical y de estilo, no invención: temperatura baja. |
| Resumir texto | `us.anthropic.claude-sonnet-4-5-20250929-v1:0` | `temperature=0.2`, `max_tokens=600` | Rigor y consistencia frente al texto original; `max_tokens` bajo fuerza la concisión. |
| Expandir ideas | `us.anthropic.claude-sonnet-4-5-20250929-v1:0` | `temperature=0.5`, `max_tokens=1500` | Punto medio: necesita algo de creatividad para desarrollar ideas, pero sin desviarse del tema original. |
| Generar variaciones creativas | `us.anthropic.claude-sonnet-4-5-20250929-v1:0` | `temperature=0.9`, `max_tokens=1200` | Se busca diversidad de propuestas para que el redactor elija; temperatura alta maximiza variación. |
| Embeddings (guía de marca / RAG) | `amazon.titan-embed-text-v2:0` | N/A (determinístico) | Solo convierte texto a vector; no hay temperatura que ajustar. |

En todas las llamadas a Claude se fija además un `stop`/límite de `max_tokens` explícito por tarea, para controlar el costo por invocación y evitar respuestas que se alarguen sin necesidad.

**Nota — inference profile e imagen en otra región.** Los modelos Claude recientes en Bedrock ya no se invocan con el ID base del modelo: requieren un *inference profile* (el prefijo `us.` indica el enrutamiento entre regiones de EE. UU.). Además, en la cuenta usada para este proyecto los modelos de texto-a-imagen de Stability solo estaban disponibles en `us-west-2`, mientras que Claude y Titan se invocan en `us-east-2` — por eso `bedrock_client.py` abre un cliente de `bedrock-runtime` por región según el servicio (ver `config.IMAGE_REGION` vs. `config.AWS_REGION`).

**Nota — solo `temperature`, no `top_p`.** El diseño original contemplaba ajustar `temperature` y `top_p` juntos por tarea, pero al probar contra Bedrock real este modelo devuelve `ValidationException: temperature and top_p cannot both be specified for this model. Please use only one.` Se optó por conservar únicamente `temperature`, que es la palanca que efectivamente enseña la regla del curso (rigor = temperatura baja, creatividad = temperatura alta); `top_p` se retiró de la petición para no violar esta restricción del modelo.
