## 3.1 · Problema y usuarios

La empresa de marketing y publicidad necesita una herramienta interna que permita a diseñadores y redactores producir imágenes y textos publicitarios apoyándose en IA generativa, de forma colaborativa y con control de calidad antes de publicar.

**Historias de usuario**

- Como **diseñador**, quiero generar imágenes desde un texto y elegir un estilo (anime, óleo, realismo), para acelerar mis propuestas visuales sin depender de un banco de imágenes externo.
- Como diseñador, quiero ver una galería de todas las imágenes generadas y descargarlas, para reutilizarlas en distintas piezas de campaña.
- Como **redactor**, quiero resumir, expandir, corregir o generar variaciones de un texto, para publicar más rápido y con mejor estilo.
- Como redactor, quiero ver el historial completo de versiones de un texto (cada edición queda como un turno nuevo en el feed), para no perder de vista cómo evolucionó el contenido.
- Como **aprobador**, quiero revisar las imágenes y textos generados por el equipo y dejar comentarios, para controlar la calidad y la coherencia de marca antes de publicar.
- Como aprobador, quiero marcar un contenido como aprobado o rechazado, para que el resto del equipo sepa qué está listo para publicar.
- Como **cualquier usuario**, quiero que la herramienta bloquee automáticamente contenido inapropiado o dañino, para no exponer a la empresa a riesgos legales o reputacionales.
